# Attributions et marques

Ce dépôt contient une intégration Home Assistant communautaire non officielle
pour les poêles à granulés MCZ Maestro.

Le fonctionnement et la cartographie du protocole MCZ Maestro ont été élaborés
en s'appuyant sur le travail publié par **Chibald/maestrogateway** :
https://github.com/Chibald/maestrogateway

Ce projet de référence est diffusé sous **GNU GPL version 3**. La présente
intégration est distribuée sous GNU GPL version 3, pour rester compatible avec
les conditions de redistribution du travail de référence. Le texte de cette
licence figure dans [LICENSE](LICENSE).

leurs propriétés. Ce dépôt ne prétend pas être affilié à ces auteurs.
