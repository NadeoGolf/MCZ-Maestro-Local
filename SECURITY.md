# Sécurité

Cette intégration pilote un équipement de chauffage via un protocole WebSocket
local non chiffré. Ne rendez jamais le port du poêle accessible depuis Internet
et conservez les protections du fabricant.

Pour signaler une vulnérabilité pouvant exposer un réseau, un système ou
permettre un pilotage non autorisé du poêle, privilégiez la fonctionnalité
**Report a vulnerability** de l'onglet **Security** du dépôt, si elle est
activée. Si elle ne l'est pas, demandez au mainteneur un canal privé avant
de transmettre les détails sensibles. Ne publiez pas de méthode d'exploitation
ou de données confidentielles dans une issue publique.

Les dysfonctionnements ordinaires de compatibilité et les demandes de
fonctionnalités peuvent être signalés dans GitHub Issues.
